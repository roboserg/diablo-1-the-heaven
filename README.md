# Diablo: The Heaven

<img src="docs/logo.png" width="300" alt="Diablo: The Heaven Logo">

A casual, quality-of-life enhanced Diablo 1 mod based on **The Hell 4** source code.

This repository is a fork of [the-hell-4-src](https://github.com/roboserg/the-hell-4-src) — an upload of The Hell 4 source files that were publicly released by [The Hell team](https://www.patreon.com/thmod).

## About

This mod enhances The Hell 4 with:
* Updated build system for modern Windows environments using **VS Code** (Visual Studio no longer required)
* Cleaned up codebase (removed dev tools and legacy files)
* Easy one-command builds via `build.ps1`
* See `docs/BUILD.md` for detailed build instructions

## Planned changes

* QoL improvements and rebalanced gameplay for a more streamlined experience
* Revert Psion damage nerf introduced in The Hell 4 to be as in The Hell 2
* Swift Learner perk to provide considerably bigger XP multiplier
