# Saves made by v0.3.0

The autotest's `classic030` phase loads this save to check that players can upgrade from v0.3.0 with their Classic items, Griswold's stash and the shared stash.

| Folder | Hero | What it's for |
|---|---|---|
| `classic` | OldClassic, a level 25 Mage in Classic mode | Items that rolled with the affixes TH4 v0.774 added to Classic, and a shared stash with v0.3.0's fingerprints. It has the same seeds as `tests\saves\v0.2.0\classic`, so 5 of its items have another affix than in that save |

In the folder:

- `th4_save_cls\th4cls_0.ksv`: the character.
- `th4_save_sp\th4shared.stv`: the shared stash.
- `oldsave-manifest.txt`: everything as v0.3.0 had it, in the same format as `tests\saves\v0.2.0` (see its README).

The save was made on 5 Nov 2026 by the v0.3.0 release (tag `v0.3.0`) with the driver used for the v0.2.0 saves, which was never committed.

It's a save file of The Heaven itself, with nothing from a third party in it.
